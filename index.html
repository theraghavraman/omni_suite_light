OVERVIEW
How it works

            
1. Ingest → extract text from documents.

2. Chunk → split content into retrieval-sized passages.

3. Embed → create local vector representations with a browser embedding model.

4. Retrieve → semantic vector + lexical hybrid search.

5. Generate → optional small local LLM answers using only retrieved context.

4. Conversion Boundary & Local Escalation

        
Some formats carry information that a browser cannot safely decode without a specialist parser. Omni should not pretend otherwise.

        

          
Browser-nativeCSV, JSON, NDJSON, GeoJSON, GPX, KML, text, coordinates, many audio files, visualization, PNG/SVG, WAV and WebM.

          
Browser best-effortRemote APIs, radio streams, unusual encodings and large datasets — dependent on CORS, memory and browser limits.

          
Local EngineFITS, NetCDF, HDF5, CDF, GRIB, huge scientific arrays, proprietary/native formats and heavy media transformations.
